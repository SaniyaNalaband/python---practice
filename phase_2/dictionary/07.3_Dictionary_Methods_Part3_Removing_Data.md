# 📖 1. `pop()`

Removes a specified key and returns its value.

### Syntax

```python
dictionary.pop(key)
```

---

## Example 1

```python
student = {
    "name": "Saniya",
    "age": 20
}

age = student.pop("age")

print(age)
print(student)
```

Output

```text
20
{'name': 'Saniya'}
```

---

## Example 2 – Missing Key

```python
student = {
    "name": "Saniya"
}

student.pop("age")
```

Output

```text
KeyError: 'age'
```

---

## Example 3 – Default Value

```python
student = {
    "name": "Saniya"
}

result = student.pop("age", "Not Found")

print(result)
print(student)
```

Output

```text
Not Found
{'name': 'Saniya'}
```

If the key doesn't exist, the default value is returned instead of raising an error.

---

# 📖 2. `popitem()`

Removes and returns the **last inserted key-value pair**.

### Syntax

```python
dictionary.popitem()
```

---

## Example

```python
student = {
    "name": "Saniya",
    "age": 20,
    "city": "Hubli"
}

item = student.popitem()

print(item)
print(student)
```

Output

```text
('city', 'Hubli')
{'name': 'Saniya', 'age': 20}
```

> **Note:** In Python 3.7+, `popitem()` removes the **last inserted** item.

---

## Empty Dictionary

```python
data = {}

data.popitem()
```

Output

```text
KeyError: 'popitem(): dictionary is empty'
```

---

# 📖 3. `clear()`

Removes all key-value pairs from the dictionary.

### Syntax

```python
dictionary.clear()
```

---

## Example

```python
student = {
    "name": "Saniya",
    "age": 20
}

student.clear()

print(student)
```

Output

```text
{}
```

The dictionary still exists, but it is empty.

# 📊 Comparison Table

| Method | Removes | Returns | Error if Missing/Empty? |
|---------|----------|----------|-------------------------|
| `pop()` | Specific key | Value | ✅ Yes (unless default is provided) |
| `popitem()` | Last inserted key-value pair | Tuple | ✅ Yes (if empty) |
| `clear()` | All items | `None` | ❌ No |

---

# ⚠️ Common Mistakes

## ❌ Using `pop()` on a Missing Key

```python
student = {"name": "Saniya"}

student.pop("age")
```

Raises

```text
KeyError
```

Use:

```python
student.pop("age", None)
```

---

## ❌ Expecting `popitem()` to Remove a Random Item

Older versions of Python behaved differently.

In **Python 3.7+**, it always removes the **last inserted item**.

---

## ❌ Thinking `clear()` Deletes the Dictionary

```python
student = {"name": "Saniya"}

student.clear()

print(student)
```

Output

```text
{}
```

The variable still exists.

---

# 💡 Best Practices

- Use `pop()` when you know the key.
- Use `pop(key, default)` if the key may not exist.
- Use `popitem()` when you want the most recently added entry.
- Use `clear()` to empty the dictionary.

---

# 🚀 Pro Tips

Safely remove a key:

```python
student = {
    "name": "Saniya"
}

removed = student.pop("age", None)

print(removed)
```

Output

```text
None
```

No error is raised.
