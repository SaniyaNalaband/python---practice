# 📖 1. `update()`

Updates an existing key or adds new key-value pairs.

### Syntax

```python
dictionary.update(other_dictionary)
```

or

```python
dictionary.update({
    "key": value
})
```

---

## Example 1 – Update an Existing Key

```python
student = {
    "name": "Saniya",
    "age": 20
}

student.update({"age": 21})

print(student)
```

Output

```text
{'name': 'Saniya', 'age': 21}
```

---

## Example 2 – Add a New Key

```python
student = {
    "name": "Saniya"
}

student.update({"city": "Hubli"})

print(student)
```

Output

```text
{'name': 'Saniya', 'city': 'Hubli'}
```

---

## Example 3 – Update Multiple Keys

```python
student = {
    "name": "Saniya"
}

student.update({
    "age": 20,
    "course": "AI ML",
    "city": "Hubli"
})

print(student)
```

Output

```text
{'name': 'Saniya', 'age': 20, 'course': 'AI ML', 'city': 'Hubli'}
```

---

## Example 4 – Update Using Another Dictionary

```python
student = {
    "name": "Saniya",
    "age": 20
}

extra = {
    "city": "Hubli",
    "country": "India"
}

student.update(extra)

print(student)
```

Output

```text
{'name': 'Saniya', 'age': 20, 'city': 'Hubli', 'country': 'India'}
```

---

## Example 5 – Using Keyword Arguments

```python
student = {
    "name": "Saniya"
}

student.update(age=20, city="Hubli")

print(student)
```

Output

```text
{'name': 'Saniya', 'age': 20, 'city': 'Hubli'}
```

# 📖 2. `setdefault()`

Returns the value of a key.

If the key does not exist, it inserts the key with a default value.

### Syntax

```python
dictionary.setdefault(key, default_value)
```

---

## Example 1 – Existing Key

```python
student = {
    "name": "Saniya",
    "age": 20
}

result = student.setdefault("age", 25)

print(result)
print(student)
```

Output

```text
20
{'name': 'Saniya', 'age': 20}
```

The dictionary is unchanged.

---

## Example 2 – Missing Key

```python
student = {
    "name": "Saniya"
}

result = student.setdefault("age", 20)

print(result)
print(student)
```

Output

```text
20
{'name': 'Saniya', 'age': 20}
```

The key is added because it did not exist.

---

## Example 3 – Without Default Value

```python
student = {
    "name": "Saniya"
}

student.setdefault("city")

print(student)
```

Output

```text
{'name': 'Saniya', 'city': None}
```

If no default value is given, `None` is used.

# ⚠️ Common Mistakes

## ❌ Expecting `update()` to Return a Dictionary

```python
student = {"name": "Saniya"}

result = student.update({"age": 20})

print(result)
```

Output

```text
None
```

`update()` always returns `None`.

---

## ❌ Thinking `setdefault()` Always Updates

```python
student = {
    "age": 20
}

student.setdefault("age", 30)

print(student)
```

Output

```text
{'age': 20}
```

The existing value is not changed.

---

# 💡 Best Practices

- Use `update()` when you want to overwrite existing values or add new keys.
- Use `setdefault()` when you want to add a key only if it doesn't already exist.

---

# 🚀 Pro Tips

`update()` overwrites existing values.

```python
student = {
    "age": 20
}

student.update({"age": 25})

print(student)
```

Output

```text
{'age': 25}
```

`setdefault()` does **not** overwrite existing values.

```python
student = {
    "age": 20
}

student.setdefault("age", 25)

print(student)
```

Output

```text
{'age': 20}
```
