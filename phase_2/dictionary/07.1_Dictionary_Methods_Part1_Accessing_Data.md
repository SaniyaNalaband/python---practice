# 📖 1. `get()`

Returns the value of a given key.

### Syntax

```python
dictionary.get(key)
```

---

## Why Use `get()`?

Instead of writing

```python
print(student["name"])
```

you can safely write

```python
print(student.get("name"))
```

Both print the same value if the key exists.

---

## Example 1

```python
student = {
    "name": "Saniya",
    "age": 20
}

print(student.get("name"))
```

Output

```text
Saniya
```

---

## Example 2

```python
print(student.get("age"))
```

Output

```text
20
```

---

## Missing Key

```python
print(student.get("marks"))
```

Output

```text
None
```

No error is raised.

---

## Default Value

```python
print(student.get("marks", 0))
```

Output

```text
0
```

If the key does not exist, the default value is returned.

---

## Difference Between `[]` and `get()`

```python
print(student["marks"])
```

Output

```text
KeyError: 'marks'
```

---

```python
print(student.get("marks"))
```

Output

```text
None
```

# 📖 2. `keys()`

Returns a view containing all keys.

### Syntax

```python
dictionary.keys()
```

---

## Example

```python
student = {
    "name": "Saniya",
    "age": 20,
    "city": "Hubli"
}

print(student.keys())
```

Output

```text
dict_keys(['name', 'age', 'city'])
```

---

## Loop Through Keys

```python
for key in student.keys():
    print(key)
```

Output

```text
name
age
city
```

---

# 📖 3. `values()`

Returns a view containing all values.

### Syntax

```python
dictionary.values()
```

---

## Example

```python
student = {
    "name": "Saniya",
    "age": 20,
    "city": "Hubli"
}

print(student.values())
```

Output

```text
dict_values(['Saniya', 20, 'Hubli'])
```

---

## Loop Through Values

```python
for value in student.values():
    print(value)
```

Output

```text
Saniya
20
Hubli
```

---

# 📖 4. `items()`

Returns all key-value pairs as tuples.

### Syntax

```python
dictionary.items()
```

---

## Example

```python
student = {
    "name": "Saniya",
    "age": 20
}

print(student.items())
```

Output

```text
dict_items([('name', 'Saniya'), ('age', 20)])
```

---

## Loop Through Items

```python
for key, value in student.items():
    print(key, ":", value)
```

Output

```text
name : Saniya
age : 20
```

# ⚠️ Common Mistakes

## ❌ Using `[]` for Missing Keys

```python
student = {"name": "Saniya"}

print(student["age"])
```

Output

```text
KeyError
```

Use:

```python
print(student.get("age"))
```

---

## ❌ Forgetting Parentheses

```python
print(student.keys)
```

Output

```text
<built-in method keys of dict object>
```

Correct:

```python
print(student.keys())
```

---

## ❌ Thinking `items()` Returns a Dictionary

```python
print(student.items())
```

It returns a **view of tuples**, not another dictionary.

---

# 💡 Best Practices

- Use `get()` when a key may not exist.
- Use `keys()` to iterate over keys.
- Use `values()` to process values.
- Use `items()` when you need both keys and values.

---

# 🚀 Pro Tips

You can convert dictionary views into lists.

```python
student = {
    "name": "Saniya",
    "age": 20
}

print(list(student.keys()))
print(list(student.values()))
print(list(student.items()))
```

Output

```text
['name', 'age']
['Saniya', 20]
[('name', 'Saniya'), ('age', 20)]
```
