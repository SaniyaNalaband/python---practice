# 📖 What is an `if...else` Statement?

An `if...else` statement is used when there are **two possible outcomes**.

- If the condition is **True**, Python executes the `if` block.
- If the condition is **False**, Python executes the `else` block.

Think of it like this:

> **IF the condition is true → Do Task A**  
> **ELSE → Do Task B**

Unlike a simple `if` statement, one of the two blocks **will always execute**.

---

# 🧠 Syntax

```python
if condition:
    # Code if condition is True
else:
    # Code if condition is False
```

---

# 🔍 Syntax Breakdown

```python
age = 20

if age >= 18:
    print("Adult")
else:
    print("Minor")
```

| Part | Meaning |
|------|---------|
| `if` | Starts the condition |
| `age >= 18` | Condition being checked |
| `:` | Begins the code block |
| `else` | Executes when the condition is False |
| Indentation | Defines each block |

---

# 🔄 Flow of Execution

```text
             Start
                │
                ▼
        Check Condition
                │
        ┌───────┴────────┐
        │                │
      True            False
        │                │
        ▼                ▼
 Execute if Block   Execute else Block
        │                │
        └───────┬────────┘
                ▼
         Continue Program
```

---

# 📖 How Does It Work?

Python follows these steps:

1. Evaluate the condition.
2. If it is `True`, execute the `if` block.
3. Otherwise, execute the `else` block.
4. Continue with the rest of the program.

---

# 1️⃣ Basic Example

```python
age = 22

if age >= 18:
    print("You are an Adult")
else:
    print("You are a Minor")
```

Output

```text
You are an Adult
```

# 📖 Indentation

Every statement inside the same block must have the same indentation.

Correct

```python
if True:
    print("Hello")
else:
    print("Bye")
```

Incorrect

```python
if True:
print("Hello")
else:
print("Bye")
```

Output

```text
IndentationError
```

# 📖 Truthy and Falsy Values

Python also accepts truthy and falsy values in `if...else`.

Example

```python
name = ""

if name:
    print("Name Entered")
else:
    print("Name is Empty")
```

Output

```text
Name is Empty
```

---

Another Example

```python
numbers = [1, 2, 3]

if numbers:
    print("List is Not Empty")
else:
    print("List is Empty")
```

Output

```text
List is Not Empty
```

# ⚠️ Common Mistakes

## ❌ Forgetting the Colon

Incorrect

```python
if age >= 18
    print("Adult")
else:
    print("Minor")
```

Correct

```python
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

---

## ❌ Wrong Indentation

Incorrect

```python
if True:
print("Hello")
else:
print("Bye")
```

Output

```text
IndentationError
```

---

## ❌ Using `=` Instead of `==`

Incorrect

```python
if marks = 90:
    print("Excellent")
```

Correct

```python
if marks == 90:
    print("Excellent")
```

---

## ❌ Writing `else` with a Condition

Incorrect

```python
else age < 18:
    print("Minor")
```

Correct

```python
else:
    print("Minor")
```

`else` **never has a condition**.

---

# 💡 Best Practices

- Use `if...else` when there are exactly **two outcomes**.
- Keep conditions simple and readable.
- Indent consistently (4 spaces).
- Use descriptive variable names.
